PowerTrace03
MongoDB Atlas

One document per board. The database is the wiring.

{
  "_id":      "AHU-07",
  "type":     "equipment",
  "parentId": "DB-L3-01",
  "phases":   3,
  "loadKW":   15,
  "on":       true
}

One field, parentId, points at whatever feeds it. $graphLookup walks those links inside the database: down for "what loses power?", up for "what feeds this?"
